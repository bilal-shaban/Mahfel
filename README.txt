محفل — دليل فعاليات الجامعة الافتراضية
=====================================
طريقة التشغيل: فك الضغط ثم افتح index.html في المتصفح (يلزم اتصال بالإنترنت لتحميل Bootstrap والخطوط والأيقونات).

الملفات:
  index.html    الرئيسية (سلايدر + تصنيفات + أحدث الفعاليات)
  events.html   كل الفعاليات مع البحث والفلترة
  event.html    تفاصيل الفعالية (event.html?id=1 ...)
  about.html    عن الدليل
  contact.html  اتصل بنا (تحقق من النموذج + Alerts)
  css/style.css  التنسيق
  js/data.js     بيانات الفعاليات (عدّلها لإضافة فعاليات)
  js/app.js      السلايدر والفلترة والتقويم والتحقق
  images/        الصور (SVG)
